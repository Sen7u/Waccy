# UI 设计：墨青工具感

## 方向

冷静、利落的生产力工具外观，对齐 Maccy「轻、快、键盘优先」，不抄 macOS 皮、不套 Avalonia 默认主题原样。

## 要点

- 主色 teal-ink（约 `#0F766E`）用于选中、置顶、主操作
- 半透明表面 + 极淡竖向渐变；默认无卡片堆叠
- 弹出层：品牌字标 + 搜索一体 → 历史列表 → 极简页脚
- 动效至少三处：弹出、选中、删除/清空
- 空状态与「暂停监听」状态要一眼可读

主题资源放在 `src/Inkboard.App/Themes/`。

## 与 Maccy 对齐的交互（必须）

| 行为 | 约定 |
|---|---|
| 尺寸 | 默认 **450×800**（`PopupHost.DefaultWidth/Height`） |
| 出现位置 | 热键唤起时贴**光标下方**（顶边对齐光标，钳入工作区） |
| 进出场 | 极短淡入/缩放（~150ms）；软隐藏移出屏幕，不 `Hide()` 以免空壳 |
| 失焦 | 点击外部 / Deactivated → 关闭 |
| 选中 | 单击或 Enter → **写入剪贴板并关闭**（默认不自动粘贴） |
| 粘贴 | Alt+Enter / Alt+单击 → 关闭后把焦点交回原应用并 Ctrl+V |
| 导航 | ↑↓ 浏览；打开时搜索框聚焦 |
| 热键 | 默认 `Ctrl+Shift+V`（Linux 无全局热键时窗口内/托盘兜底） |
